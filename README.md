# День Икс

«День Икс» — календарь с виджетами и заметками для Android и компьютера.

- Виджеты месяца, ближайших встреч, праздников, даты, таймера и заметок.
- Праздники и производственный календарь России.
- Свои даты: дни рождения, годовщины, события.
- Заметки с оформлением: заголовки, списки, задачи, цветные блоки, ссылки.
- Синхронизация заметок между устройствами через ваш Google Диск (подписка «Бро»).

Всё хранится на вашем устройстве. У приложения нет своего сервера, разработчик не получает ваши данные.

[Политика конфиденциальности](https://kuvaldosik.github.io/den-iks-data/privacy.html)

Связь с разработчиком: [kondrat999@yandex.ru](mailto:kondrat999@yandex.ru)

## Что в этом репозитории

Общедоступные данные, которые приложение загружает из интернета:

- `ru/` — праздники и производственный календарь;
- `bro/` — список действующих ключей подписки «Бро»;
- `privacy.html` — политика конфиденциальности.
